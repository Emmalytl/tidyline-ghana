# Tidyline Ghana — Admin, Staff & Accounting update

This version keeps the public customer booking flow and adds the requested operations changes.

## Required Supabase setup

1. Open Supabase SQL Editor.
2. Run the complete `supabase/schema.sql` file from this ZIP.
3. In the VS Code terminal, from the project root, run:

```powershell
supabase link --project-ref YOUR_PROJECT_REF
supabase functions deploy create-staff-user
```

The Edge Function is configured with `verify_jwt = false` and performs its own access-token check. This avoids the common gateway JWT mismatch that can surface as "Failed to send a request to the Edge Function" while still preventing unauthorised staff creation.

## Staff creation

Admin → Staff → Add staff creates:
- Supabase Auth login
- Staff profile
- Basic salary (default GH₵2,000)
- Monthly allowance
- Monthly bonus

If the function fails, the Admin page now attempts to show the actual error returned by the function instead of only the generic invoke error.

## Payroll/accounting

Admin → Accounting includes:
- Monthly service revenue
- Revenue generated by each assigned staff member
- 40% administrative fee on service revenue
- Employee SSNIT deduction: 5.5% of basic salary
- Employer contribution: 13% of basic salary
- PAYE/income tax estimate using the resident monthly GRA bands included in the app
- Gross payroll, net pay and employer contribution

Staff can see their own:
- Basic salary
- Allowances
- Bonuses
- Employee SSNIT deduction
- PAYE
- Employer contribution
- Take-home pay

## Laundry

Laundry is now a service in the customer dropdown. For other cleaning services, the customer can optionally tick **Add laundry service**. The current default laundry price is GH₵250 and can be changed in the source when the final business price is decided.

## Branding

The Tidyline logo is used in the public navigation, Admin login/navigation/header and Staff login/navigation/header. Browser titles are also set for the Admin and Staff portals.
